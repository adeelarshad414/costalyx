# 17-CUSTOMER-HANDOVER-COMPETITIVE-RUN.md - Handover-Grade, Market-Benchmarked Run

## When to use this
The final-mile prompt. It runs doc 16's five gates in full (audit, build/fix,
harden, elevate, docs-truth, converge) and adds three dimensions the chain does
not yet cover: competitive parity and differentiation against market tools,
formal conformance to industry best-practice frameworks, and a customer
handover package.

```markdown
# Costalyx - Customer Handover & Competitive Excellence Run

## Mission
Execute 16-ULTIMATE-MASTER-RUN.md end to end, then complete:

1. Competitive parity and differentiation audit against IBM Cloudability,
   CloudZero, Kubecost, Vantage, Flexera One, and native AWS/Azure/GCP cost
   tools. Produce COMPETITIVE-MATRIX.md with source-backed parity/ahead/behind
   judgments. Every Costalyx behind-cell is fixed in this run if in scope or
   logged as a roadmap gap with reasoning.
2. Best-practice framework conformance in CONFORMANCE.md covering FinOps
   FOCUS/Framework, AWS/Azure/GCP cost pillars, SRE SLOs, DevSecOps/OWASP ASVS
   Level 2 target controls, 12-factor/container practices, and WCAG 2.1 AA
   evidence.
3. Customer handover package under handover/: package index, operations
   runbooks, installation guide, onboarding checklist, security overview,
   SLO/support guide, demo script plus demo seed profile, and go-live
   checklist.

## Stop conditions
- HANDOVER-READY: doc 16 SHIPPED condition is met, COMPETITIVE-MATRIX.md has no
  unresolved Costalyx behind-cells, CONFORMANCE.md has no unaccepted gaps, and
  every handover artifact is execution-verified.
- EXHAUSTED: every remaining item is environment- or human-blocked with
  evidence, and written-but-unverified handover artifacts are not called
  verified.

## Non-negotiable honesty rule
Dummy data is verified(mock), not production cloud proof. Real production cloud
proof still requires real customer read-only AWS, Azure, and GCP references
plus Costalyx broker identities.
```
